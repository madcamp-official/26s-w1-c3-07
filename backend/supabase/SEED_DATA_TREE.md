# 더미 데이터 "내 강의" 트리 구조

`seed.sql`로 넣은 데이터를 계정별·모드별로 "내 강의" 페이지에 들어갔을 때 보이는 트리 구조로 정리한 문서입니다.

- **강의자 모드**: `created_by = 나` AND `created_mode = 'lecturer'`인 노드만 보임
- **수강생 모드 - 내가 만든 폴더**: `created_by = 나` AND `created_mode = 'student'`인 노드
- **수강생 모드 - 즐겨찾기**: `my_nodes`에 등록한 남의 강의/폴더. `folder_id`가 있으면 "내가 만든 폴더" 밑에 끼워 넣어 보여주고, `folder_id`가 `null`이면 최상위에 표시

각 항목엔 `(내 것)` / `(즐겨찾기, 실제 만든 사람)`을 표기했습니다.

## 정리: 즐겨찾기 관계 요약

| 즐겨찾기한 사람 | 대상 | 실제 만든 사람 | 내 폴더 어디에 정리했나 |
|---|---|---|---|
| A | 배열과 연결 리스트 (강의) | B | 컴퓨터 과학 › 자료구조 |
| A | 운영체제 (폴더) | B | 컴퓨터 과학 (바로 밑) |
| A | 수학 (폴더) | C | 최상위 |
| A | AI 세미나 (강의) | B | 최상위 |
| A | 커리어 토크 (강의) | C | 최상위 |
| A | 파이썬 워크샵 (강의) | B | 최상위 |

즐겨찾기 대상(`node_id`)의 실제 `parent_id`는 원래 만든 사람 기준 그대로(전부 최상위, `null`)이고, 위 표의 "정리 위치"는 A 본인의 `my_nodes.folder_id`에만 저장되는 개인적인 값입니다 — 남의 트리 구조를 바꾸는 게 아닙니다.
