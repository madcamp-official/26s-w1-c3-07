# Qroom Frontend

React, TypeScript, Vite, Tailwind CSS 기반의 Qroom 프론트엔드입니다.

```bash
npm install
npm run dev
```

## 구조

- `src/pages`: URL 단위 페이지
- `src/components`: 재사용 가능한 UI와 도메인 컴포넌트
- `src/layouts`: 공통 페이지 레이아웃
- `src/hooks`: 화면 상태와 비동기 데이터 훅
- `src/services`: 향후 Supabase로 교체할 API 계층
- `src/mock`: 개발용 목 데이터
- `src/types`: 도메인 타입
- `src/utils`: 공통 유틸리티
